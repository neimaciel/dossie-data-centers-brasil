# Dossiê: data centers no Brasil — ênfase Paraná

Inventário visual com fontes (corte 29/10/2026, America/Sao_Paulo): capacidade instalada e em obras (JLL), fila de energia (EPE), projetos nomeados de hyperscale/IA, frotas dos operadores e todos os sites mapeados no Paraná.

## Stack

- Vite + React + TypeScript
- Site estático (sem backend)

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy (Vercel)

Projeto pronto para deploy estático na Vercel (`npm run build` → `dist/`).

## Nota metodológica

Cada linha nomeada tem link-fonte. MW sem divulgação oficial ficam como “Não divulgado”. Este é um dossiê de acompanhamento — não um censo regulatório oficial.
